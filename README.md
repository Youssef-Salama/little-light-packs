# Little Light level packs

Story data only, no code. These are the optional "11 to 17" and "Over 17" content packs that the Little Light app (a cartoon 3D New Testament adventure for Coptic Orthodox children) downloads when a grown-up chooses a higher content level in Parents settings.

Each release (`v<app version>`) holds `level_from11.zip`, `level_over17.zip` and a `level_<id>.json` manifest with sizes and SHA-256 checksums. The app verifies every file before it uses a pack.

The app itself lives in a private repository.
